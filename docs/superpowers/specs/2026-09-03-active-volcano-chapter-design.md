# 활화산 챕터 설계

## 목표

푸른 해안 다음 장을 네 개의 물리 맵으로 확장한다. 플레이어는 선발대의 전투·호위 담당 가렌을 추적하고, 선발대장이 분화를 막기 위해 직접 코어 조각에 손댄 뒤 오염되었다는 진실을 확인한다. 구조 준비를 완료하면 오염된 대장을 구하고 세 직업용 히든 무기 세트를 얻는다. 준비 없이 최종 진입을 확정하면 대장을 구하지 못하지만 세 번째 코어 조각과 본편 진행은 유지된다. 어느 분기든 픽셀 코어 성역 입구가 열린다.

## 범위와 호환성

- 기존 `volcano` mapId는 첫 맵으로 유지해 v6 저장의 활화산 해금을 보존한다.
- 활화산은 `2160 × 1800` 네 맵으로 나뉜다.
- 성역은 다음 장의 시작점만 제공하는 `2160 × 1800` 안전 맵으로 연다. 본편 성역 전투와 결말은 이번 범위가 아니다.
- 기존 숲·해안 진행, 21종 상점 무기, 일반 몬스터, 솔로/온라인 모드와 보스 보상은 유지한다.
- 일반 몬스터는 계속 브라우저별 개인 사냥이고 최종 맵의 선발대장 보스만 협동 상태를 공유한다.

## 맵과 진행

| 순서 | mapId | 표시명 | 필수 목표 | 선택 구조 준비 |
|---:|---|---|---|---|
| 1 | `volcano` | 잿불 관문 | 압력 봉인장치 복구, 가렌의 그을린 인장 확인 | 잿불 냉각 쐐기 |
| 2 | `volcano-magma-route` | 용암 수송로 | 서·중앙·동 용암 밸브 복구, 가렌 호위 기록 확인 | 수송로 냉각 쐐기 |
| 3 | `volcano-observatory` | 붕괴한 관측소 | 관측소 안정기 복구, 운반 명령과 코어 접촉 기록 확인 | 관측소 냉각 쐐기 |
| 4 | `volcano-core-caldera` | 화구 코어 제단 | 오염된 선발대장 처치, 구출 또는 일반 분기 확정, 세 번째 코어 조각 회수 | 없음 |

맵 1의 필수 목표가 끝나면 맵 2, 맵 2의 필수 목표가 끝나면 맵 3이 열린다. 맵 3의 필수 목표가 끝나면 화구 진입 제어장치가 활성화된다.

- 냉각 쐐기 3개를 모두 모은 경우: `구조 장비를 완성하고 화구로 간다`만 제공하고 `routeDecision: "rescue"`로 최종 맵을 연다.
- 하나라도 부족한 경우: `구조 준비를 더 한다`와 `구조를 포기하고 지금 진입한다`를 함께 제공한다. 첫 선택은 진행을 바꾸지 않고 되돌아갈 수 있게 한다. 두 번째 선택만 `routeDecision: "proceed"`로 영구 확정하고 최종 맵을 연다.
- 경고 문구는 대장을 구하지 못하며 히든 무기를 얻지 못하지만 본편 진행은 가능하다는 결과를 진입 전에 명시한다.
- routeDecision이 정해진 뒤에는 냉각 쐐기를 추가 획득하거나 분기를 바꿀 수 없다.

## 사건의 진실

대장은 가렌에게 해안에서 회수한 코어 조각을 활화산 관측소로 운반하라고 명령했다. 관측소 기록에는 외부 배신자가 아니라 선발대장 자신이 분화를 멈추기 위해 봉인 규정을 어기고 코어에 직접 손댄 사실이 남아 있다. 접촉 직후 코어의 변이 파동이 대장에게 옮겨 갔고, 가렌은 대장을 지키며 냉각 쐐기 세 개를 흩어 놓았다. 따라서 지역의 질문 “누가 픽셀 코어에 손댔는가?”의 답은 `선발대장 자신`이지만, 목적은 조각 탈취가 아니라 즉시 폭발을 막는 것이었다.

## 저장 모델

`worldProgress.chapters.volcano`는 다음 값만 저장한다.

```js
{
  repairedDeviceIds: [],
  collectedClueIds: [],
  coolantAnchorIds: [],
  routeDecision: null,          // null | "rescue" | "proceed"
  eruptionTriggered: false,
  coopBossDefeated: false,
  captainOutcome: null,         // null | "rescued" | "lost"
  hiddenWeaponRewardClaimed: false,
  coreFragmentObtained: false,
  sanctuaryUnlocked: false,
}
```

정규화는 다음 파생 관계를 복구한다.

- `coreFragmentObtained`이면 `sanctuaryUnlocked`, 활화산 완료, 성역 지역·맵 해금을 복구한다.
- `captainOutcome`이 있으면 `coopBossDefeated`를 복구한다.
- `hiddenWeaponRewardClaimed`이면 `captainOutcome: "rescued"`를 복구한다.
- `routeDecision`은 정확한 문자열 두 개만 허용한다.
- 손상된 배열과 문자열 boolean은 진행으로 인정하지 않는다.

저장 키는 `pixel-world.progress.v7:<nickname>`으로 올리고 v6부터 v1까지 순서대로 읽어 v7에 쓴다. v6의 공통 진행·장비·보상 영수증·해안 챕터를 그대로 보존하고 활화산 기본 상태만 추가한다.

## 화산 폭발 게임 규칙

최종 진입 분기를 확정하면 `eruptionTriggered`가 저장된다. 붕괴한 관측소와 화구 코어 제단에서만 로컬 분화 위험을 실행한다.

- 한 주기는 8초다.
- 0~5.5초는 대기, 5.5~7초는 반경 110px 낙하 지점 경고, 7초에 한 번 충돌, 7~8초는 잔해 소멸이다.
- 경고 시작 때 플레이어 진행 방향 150px 앞을 목표로 고정하고 월드 경계 안으로 제한한다.
- 충돌 시 원 안의 플레이어에게 20 피해를 한 번 적용한다.
- 대화·인벤토리·상점·QA·포탈 전환·사망 중에는 주기를 일시 정지한다.
- 솔로와 온라인 모두 환경 피해는 해당 브라우저 플레이어에게만 적용한다. Firebase에 위험 상태나 피해를 쓰지 않는다.
- 세 번째 코어 조각을 회수하면 분화 위험을 중단한다.

## 대장 보스와 분기

기존 Firebase bossId `volcano-core-imp`는 데이터 호환을 위해 유지하되 전투 맵을 `volcano-core-caldera`, 이름을 `오염된 선발대장`으로 바꾼다. HP 배율, EXP 220, Gold 150, 3분 재등장, 기여 보상 규칙은 유지한다.

보스를 처치하면 `coopBossDefeated`를 기록한다.

- `routeDecision: "rescue"`: 대장 구출 상호작용을 열고 완료 시 `captainOutcome: "rescued"`와 히든 무기 보상을 같은 로컬 저장에 원자적으로 기록한다.
- `routeDecision: "proceed"`: 대장의 마지막 경고 상호작용을 열고 완료 시 `captainOutcome: "lost"`를 기록한다. 히든 무기는 지급하지 않는다.
- 양쪽 모두 결과 확정 후 코어 조각 상호작용이 열린다.
- 저장 실패 시 월드 진행과 장비 지급을 모두 이전 상태로 되돌린다.

## 히든 무기

구출 성공 시 현재 직업 하나가 아니라 세 직업 세트를 계정 장비에 함께 지급한다. 직업 변경이 가능한 저장 구조에서 한 번뿐인 분기 보상을 놓치지 않게 하기 위함이다. 자동 장착은 하지 않는다.

| 직업 | id | 이름 | 피해 | 사거리 | 추가 수치 | Q 재사용 |
|---|---|---|---:|---:|---|---:|
| 검사 | `volcanic-heartblade` | 불굴의 화심검 | 2.75 | 80px | 회전 베기 기존 공식 | 3.0초 |
| 궁수 | `ember-tracker-bow` | 불굴의 잿불궁 | 2.65 | 500px | 투사체 750px/s | 3.2초 |
| 마법사 | `leyflame-core-staff` | 불굴의 용맥지팡이 | 2.85 | 405px | 투사체 575px/s, 폭발 156px | 3.4초 |

세 무기는 `requiredLevel: 30`, `price: null`, `sellPrice: null`, `rewardOnly: true`, `tier: 8`이다. 대장간 구매·판매 목록에서는 숨기고, 보유한 경우 현재 직업 인벤토리와 전투·캐릭터 외형·원격 플레이어 외형에만 나타난다. 직접 구매와 판매 요청은 `reward_only`로 거부한다.

## 성역 개방

세 번째 코어 조각을 회수하면 활화산을 완료하고 `sanctuary` 지역과 `sanctuary` 맵을 연다. 화구 코어 제단과 성역 입구 사이 왕복 포탈을 제공한다. 성역 입구는 몬스터와 보스가 없는 안전지대이며 “세 코어 조각이 성역의 문을 열었다”는 도착 안내만 제공한다.

## 온라인·보안

- 플레이어와 채팅의 허용 물리 mapId에 활화산 신규 세 맵과 `sanctuary`를 추가한다.
- 활화산 네 맵과 성역 경계는 모두 `2160 × 1800`이다.
- 협동 보스 읽기·state·attack·reward 경로의 활화산 전투장은 `volcano-core-caldera`만 허용한다.
- 공격 요청의 직업별 무기 허용 목록에 해당 히든 무기를 하나씩 추가한다.
- Firebase 규칙 emulator에서 신규 mapId 경계, 잘못된 레거시 보스 맵, 히든 무기 직업 불일치를 검증한다.

## 완료 기준

- 세 직업 모두 정상 진행으로 네 맵을 순서대로 통과한다.
- 구조 준비 3/3은 대장 구출·세 히든 무기·코어·성역으로 이어진다.
- 준비 부족 경고에서 돌아가기는 상태를 바꾸지 않고, 명시적 포기는 일반 루트·코어·성역으로 이어진다.
- 저장 후 재접속해 맵 해금, 분기, 보상, 코어와 성역을 복구한다.
- 분화 경고·회피·피해·일시 정지·코어 후 중단이 자동 테스트와 브라우저에서 확인된다.
- 솔로/온라인 보스, Firebase 보안 규칙, 기존 600개 회귀 테스트가 모두 통과한다.
- 변경된 정적 모듈은 `20260903-volcano` 물리 release URL로 연결되어 두 호스트의 오래된 캐시와 섞이지 않는다.
