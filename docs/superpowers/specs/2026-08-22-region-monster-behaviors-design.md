# 지역별 신규 몬스터와 행동 상태 머신 설계

## 목표

픽셀 월드의 해안가, 활화산, 태고의 숲에 신규 몬스터 7종을 추가한다. 기존 몬스터와 출현 위치는 모두 유지하면서 각 신규 몬스터가 지역을 구분하는 대표 행동을 사용하도록 한다.

이번 작업은 기존의 단순 추적·접촉 피해 흐름을 데이터 기반 행동 상태 머신으로 확장한다. 행동은 공통적으로 `idle → telegraph → attack → cooldown` 상태를 사용하고, 분열·순간이동·잠복·위장·재생·포자 둔화는 독립 행동 모듈로 구현한다.

완료된 플레이 흐름은 다음과 같다.

1. 플레이어가 기존 포털을 통해 해안가, 활화산, 태고의 숲에 진입한다.
2. 기존 몬스터와 함께 배치된 신규 몬스터를 발견한다.
3. 바닥 표시, 색 변화, 잔상 등으로 대표 기술의 준비 동작을 확인하고 대응한다.
4. 몬스터를 처치해 종류별 고정 EXP와 Gold를 받는다.
5. 보상은 기존 진행 데이터 v3에 즉시 저장된다.

## 이번 범위

- 신규 몬스터 7종과 지역별 신규 스폰 15개
- 신규 몬스터의 픽셀 도형 외형과 지역별 색상
- 데이터 기반 행동 정의와 공통 상태 전환
- 돌진, 물기, 분열, 순간이동, 잠복 돌진, 위장, 재생, 포자 둔화
- 신규 몬스터의 고정 EXP·Gold 보상
- 플레이어 이동속도 감소 상태와 시각 피드백
- 단위·통합·렌더링·브라우저 회귀 검증

## 이번 범위에서 제외

- 해안가의 전기, 끌어당기기, 추가 독 효과
- 활화산의 화상, 폭발, 지속 장판, 영구 또는 임시 지형 변화
- 태고의 숲의 속박과 별도 독 피해
- 몬스터 재생성
- 몬스터 상태의 서버 동기화
- 신규 드롭 아이템과 퀘스트
- 저장 형식 변경

제외한 기술은 이번 행동 이벤트 인터페이스 위에 후속 작업으로 추가한다.

## 행동 상태 머신

### 공통 상태

각 몬스터 인스턴스는 다음 행동 필드를 가진다.

- `behavior`: 정의에 등록된 행동 ID
- `behaviorState`: `idle`, `chasing`, `telegraph`, `attack`, `cooldown`, `returning`, `dying` 중 하나
- `behaviorTime`: 현재 상태에서 경과한 시간
- `cooldownRemaining`: 다음 대표 기술까지 남은 시간
- `attackSequence`: 대표 기술을 시작할 때마다 증가하는 정수
- `attackApplied`: 현재 공격에서 피해 이벤트를 이미 발생시켰는지 여부
- `lastDamagedAgo`: 마지막으로 피해를 받은 뒤 경과한 시간
- `generation`: 분열 세대. 일반 몬스터와 부모 슬라임은 0, 자식 슬라임은 1

상태 전환은 프레임 수가 아니라 누적 초 단위 시간으로 계산한다. 한 프레임의 `dt`가 여러 상태 경계를 지나더라도 공격, 분열, 보상 이벤트는 각각 한 번만 발생한다.

`dying`은 다른 행동보다 우선한다. 사망한 몬스터는 이동, 공격, 재생, 접촉 피해를 중지한다.

### 행동 이벤트

`updateEnemies`는 갱신된 몬스터 배열과 함께 행동 이벤트 목록을 반환한다.

```js
{
  enemies,
  events: [
    { type: "damage-player", enemyId, attackId, amount, source },
    { type: "apply-player-status", enemyId, status: "slow", multiplier, duration },
    { type: "spawn-enemies", enemyId, kind, count, childHp, origin },
  ],
}
```

- `attackId`는 몬스터 ID와 `attackSequence`를 조합해 같은 공격 피해를 중복 적용하지 않게 한다.
- `game.js`는 이벤트를 순서대로 소비하고 플레이어가 사망하면 남은 피해 이벤트를 중지한다.
- 알 수 없는 이벤트는 상태를 변경하지 않고 무시한다.
- 기존 몬스터는 현재 추적·접촉 피해 흐름을 유지하고 불필요한 대표 기술 상태를 만들지 않는다.

## 대표 행동 상세

### 송곳니 상어: 돌진

- 플레이어가 320픽셀 안에 있고 재사용시간이 끝나면 돌진을 준비한다.
- `telegraph`는 0.55초이며 시작할 때 플레이어 위치로 방향을 고정한다.
- 준비 중 상어의 몸과 진행 방향 바닥선을 청록색과 흰색으로 점멸한다.
- `attack`은 0.45초이며 초당 420픽셀로 고정 방향을 이동한다.
- 플레이어와 충돌하면 피해 50을 한 번 적용하고 즉시 `cooldown`으로 전환한다.
- 장애물과 충돌해도 즉시 돌진을 종료한다.
- 재사용시간은 2.4초다.
- 준비 조건을 만족하지 않으면 기존 추적과 최초 위치 복귀를 사용한다.

### 해적선 상어: 물기

- 플레이어를 추적하다가 중심 사이 거리가 62픽셀 이하이고 재사용시간이 끝나면 물기를 준비한다.
- `telegraph`는 0.35초이며 보라색 입과 흰색 이빨을 크게 벌린다.
- `attack`은 0.18초이며 플레이어를 향해 최대 34픽셀 전진한다.
- 물기 부채꼴 범위에 플레이어가 있으면 피해 55를 한 번 적용한다.
- 재사용시간은 1.8초다.
- 물기 공격 이외의 일반 접촉은 피해를 주지 않는다.

### 마그마 슬라임: 분열

- 부모는 기존 슬라임처럼 추적하고 접촉 시 피해 20을 준다. 접촉 피해 재사용시간은 1초다.
- 부모 HP 10이 0이 되면 즉시 EXP 15와 Gold 10을 한 번 지급하고 기존 0.65초 사망 연출을 시작한다.
- 사망 시점에 주입된 난수로 분열 수를 한 번 결정한다. 난수가 0.5 미만이면 2마리, 그 외에는 3마리다.
- 사망 연출이 끝날 때 부모 위치 주변의 방사형 후보 좌표에서 자식을 생성한다.
- 2마리 분열이면 각 자식 HP는 5, 3마리 분열이면 각 자식 HP는 3이다.
- 자식 공격력은 20, 이동속도는 95, 반경은 12다.
- 자식의 내부 종류는 `magma-slime-small`이고 `generation`은 1이다.
- 자식은 분열하지 않고 EXP·Gold와 퀘스트 진행을 지급하지 않는다.
- 생성 후보가 장애물 또는 월드 경계와 겹치면 다음 후보를 사용한다. 유효한 후보가 부족하면 생성 가능한 자식만 생성한다.
- 한 부모에서 활성 자식은 최대 3마리다.

### 불꽃 도깨비: 고속 이동과 순간이동

- 기본 이동속도는 초당 148픽셀이다.
- 추적 중 재사용시간이 끝나면 0.4초 동안 검정 잔상과 주황색 불씨를 남기며 사라진다.
- 사라진 동안 이동과 접촉 피해를 중지하고 플레이어 공격 대상에서도 제외한다.
- 플레이어로부터 110~180픽셀 거리의 원주에서 최대 8개의 후보 위치를 검사한다.
- 월드 경계, 장애물, 포털 중심 180픽셀 안전범위, 플레이어 중심 80픽셀 이내를 제외한다.
- 첫 유효 위치로 이동한 뒤 0.25초 동안 진홍색 재등장 예고를 표시한다.
- 순간이동 자체는 피해를 주지 않는다. 재등장 후 일반 추적으로 돌아가며 접촉 시 피해 60을 한 번 적용한다.
- 접촉 피해 재사용시간은 1.2초, 순간이동 재사용시간은 3초다.
- 유효한 순간이동 후보가 없으면 현재 위치에 재등장하고 재사용시간을 시작한다.

### 고대 멧돼지: 잠복 돌진

- 플레이어가 330픽셀 안에 있고 재사용시간이 끝나면 잠복을 시작한다.
- `telegraph`는 0.7초다. 몸은 숨기고 이동 방향을 보여주는 황토색 흙먼지와 땅의 흔들림만 표시한다.
- 잠복 중에는 이동과 접촉 피해를 중지하고 플레이어 공격 대상에서 제외한다.
- 준비 시작 시 플레이어 위치로 돌진 방향을 고정한다.
- `attack`은 0.5초이며 초당 440픽셀로 이동한다.
- 플레이어와 충돌하면 피해 45를 한 번 적용하고 돌진을 종료한다.
- 장애물과 충돌해도 즉시 종료한다.
- 재사용시간은 3.4초다.

### 이끼 트롤: 위장과 재생

- `idle`과 `returning` 상태에서 플레이어가 280픽셀 밖에 있으면 투명도를 25%로 낮춘다.
- 플레이어가 280픽셀 안에 들어오거나 트롤이 피해를 받으면 즉시 완전히 드러난다.
- 마지막 피격 후 3초가 지나고 `dying`이 아니면 초당 HP 4를 재생한다.
- 재생은 최대 HP 100을 넘지 않으며 소수 누적값을 유지해 프레임 속도와 관계없이 같은 양을 회복한다.
- 재생 중 피해를 받으면 재생을 즉시 중지하고 대기시간을 다시 3초로 설정한다.
- 플레이어를 추적해 접촉하면 피해 50을 한 번 적용한다. 접촉 피해 재사용시간은 1.2초다.

### 고대 버섯충: 포자 둔화

- 플레이어가 240픽셀 안에 있고 재사용시간이 끝나면 포자를 준비한다.
- `telegraph`는 0.6초이며 반경 120픽셀의 보라색 원과 퍼지는 포자 입자를 표시한다.
- 준비가 끝날 때 플레이어가 반경 120픽셀 안에 있으면 이동속도 배율 0.65, 지속시간 2.5초의 `slow` 이벤트를 한 번 발생시킨다.
- 포자는 직접 HP 피해를 주지 않는다.
- 둔화가 이미 적용 중이면 배율을 더 낮추지 않고 남은 시간을 2.5초로 갱신한다.
- 포자 재사용시간은 4초다.
- 버섯충과 직접 접촉하면 피해 35를 한 번 적용한다. 접촉 피해 재사용시간은 1초다.

## 플레이어 둔화 상태

플레이어는 저장되지 않는 전투 상태로 다음 값을 가진다.

```js
statusEffects: {
  slow: { multiplier: 1, remaining: 0 },
}
```

- 평상시 이동 배율은 1이다.
- 포자 적중 시 이동 배율을 0.65로 설정하고 남은 시간을 2.5초로 갱신한다.
- 실제 이동 속도 계산에만 배율을 적용한다. 공격, 포털 전환, 카메라, 원격 위치 전송 형식은 변경하지 않는다.
- 둔화 중 플레이어 주변에 보라색 포자를 표시하고 HUD 알림으로 `포자에 노출되어 이동속도가 감소했습니다.`를 한 번 표시한다.
- 남은 시간이 0이 되면 배율을 1로 복원한다.
- 사망, 부활, 게임 퇴장, 재입장, 지역 이동 시 둔화를 제거한다.

## 픽셀 외형과 전투 예고

신규 이미지를 내려받지 않고 Canvas의 정수 좌표 사각형과 제한된 도형으로 기존 픽셀 스타일을 유지한다.

### 해안가 색상

- 기본 색상: 청록 `#159a9c`, 모래색 `#d7b878`, 흰색 `#f4f7ed`, 보라색 `#7650a8`
- 송곳니 상어는 청록 몸, 흰 배와 이빨, 모래색 지느러미를 사용한다.
- 해적선 상어는 더 어두운 청록 몸, 보라색 해적 두건, 흰 이빨을 사용한다.

### 활화산 색상

- 기본 색상: 검정 `#1b1719`, 진홍 `#a91f2c`, 주황 `#f05a24`, 노랑 `#ffc857`
- 마그마 슬라임은 검은 굳은 표면 사이로 주황·노랑 용암 균열을 표시한다.
- 자식은 같은 외형을 반경과 크기에 맞춰 축소한다.
- 불꽃 도깨비는 검정 중심부, 진홍 외곽, 주황·노랑 불꽃 끝을 사용한다.

### 태고의 숲 색상

- 기본 색상: 짙은 초록 `#234f32`, 갈색 `#704b32`, 황토색 `#b58a4a`, 이끼색 `#6f8f3d`, 보라색 `#76508f`
- 고대 멧돼지는 갈색 몸, 황토색 엄니, 짙은 초록 등털을 사용한다.
- 이끼 트롤은 갈색 나무껍질 몸과 이끼색 덮개를 사용해 나무 지형과 비슷하게 보이게 한다.
- 고대 버섯충은 짙은 초록 몸, 보라색 버섯 갓, 황토색 포자낭을 사용한다.

피격 시 기존 흰색 점멸, 흔들림, 피해 숫자, 밀쳐내기를 유지한다. 대표 기술의 준비 표시는 몬스터 몸보다 앞에 렌더링하고 채도와 형태를 다르게 해 지역 바닥 위에서도 구분되게 한다.

## 모듈 책임

### `src/enemy-definitions.js`

- 기존 및 신규 몬스터 능력치와 색상 제공
- 행동 ID와 기술 수치 제공
- 정의 객체를 불변 데이터로 노출
- 알 수 없는 종류에 대한 안전한 조회 함수 제공

### `src/enemy-behaviors.js`

- 대표 행동별 상태 전환
- 이동 의도와 충돌 처리 요청 생성
- 피해, 상태이상, 분열 이벤트 생성
- 난수 주입을 통한 순간이동 후보와 분열 수 결정
- DOM, Canvas, 저장소에 직접 접근하지 않음

### `src/enemies.js`

- 월드 스폰으로 몬스터 인스턴스 생성
- 공통 피격, 밀쳐내기, 사망, 추적, 복귀 처리
- 행동 모듈 실행과 행동 이벤트 수집
- 신규 몬스터별 픽셀 외형과 예고 효과 렌더링

현재 파일이 몬스터 데이터, 시뮬레이션, 렌더링을 모두 포함하고 있으므로 정의와 행동만 별도 모듈로 분리한다. 렌더링은 이번 범위에서 `enemies.js`에 유지하고 파일이 과도하게 커질 경우에만 후속 작업에서 분리한다.

### `src/game.js`

- `updateEnemies` 결과의 몬스터 배열과 이벤트 소비
- 공격 ID별 플레이어 피해 중복 방지
- 플레이어 둔화 적용과 HUD 알림
- 몬스터 사망 시 기존 보상·퀘스트·저장 흐름 유지
- 부모 마그마 슬라임 보상과 자식 무보상 구분

### `src/player-combat.js`

- 둔화 남은 시간 감소와 이동 배율 복원
- 사망·부활 초기화 헬퍼 제공

### `src/world-data.js`

- 기존 스폰을 유지하면서 신규 15개 스폰 추가

### `src/player-progression.js`

- 신규 부모 몬스터 7종의 고정 보상 등록
- `magma-slime-small`은 보상표에 등록하지 않음

## 데이터와 저장

- 신규 몬스터 상태는 각 브라우저 클라이언트에서만 실행한다.
- Firebase 플레이어 위치 데이터와 채팅 데이터 형식은 변경하지 않는다.
- EXP와 Gold는 기존 진행 데이터 v3에 저장한다.
- 둔화, 몬스터 HP, 행동 상태, 분열 자식은 저장하지 않는다.
- 새로운 영속 필드가 없으므로 저장 버전 이전은 수행하지 않는다.
- 알 수 없는 몬스터 종류는 생성에서 제외하고 게임 실행을 계속한다.
- 보상표에 없는 종류는 보상을 지급하지 않는다.

## 오류와 경계 조건

- 유효한 순간이동 위치를 찾지 못하면 현재 위치를 유지하고 순간이동 재사용시간을 시작한다.
- 분열 후보 위치가 모두 막혀 있으면 자식을 생성하지 않지만 부모 보상은 유지한다.
- 정의되지 않은 행동 ID는 기존 추적·접촉 행동으로 대체한다.
- 장애물에 막힌 돌진은 X축과 Y축을 따로 미끄러지지 않고 즉시 종료한다.
- `dying` 상태 진입 후 같은 몬스터에게 추가 공격이나 보상을 적용하지 않는다.
- 한 공격으로 부모와 다른 몬스터가 동시에 죽어도 HUD와 저장은 기존처럼 공격 처리 마지막에 한 번 갱신한다.
- 마그마 슬라임의 분열 이벤트는 사망 연출이 끝나는 프레임에 한 번만 발생한다.
- 플레이어 사망 이후 같은 프레임에 남은 몬스터 피해 이벤트는 적용하지 않는다.
- 지역 이동과 게임 종료 시 현재 지역의 동적 분열 자식과 행동 이벤트를 폐기한다.
- 트롤의 재생 소수 누적 오차는 HP를 최대 HP로 제한해 넘치지 않게 한다.
- 프레임 간격이 길어도 둔화 남은 시간과 재사용시간은 0 미만으로 내려가지 않는다.

## 테스트와 완료 조건

### 단위 테스트

- 기존 5종과 신규 7종 정의의 HP, 공격력, 속도, 반경, 행동 ID
- 신규 7종의 고정 EXP와 Gold
- 지역별 기존 종류 유지와 신규 스폰 수, 전체 개체 수 14·13·16
- 송곳니 상어의 준비, 방향 고정, 돌진, 1회 피해, 장애물 종료, 재사용시간
- 해적선 상어의 거리 조건, 물기 예고, 전진, 1회 피해
- 마그마 슬라임의 난수 경계별 2·3마리 분열과 자식 HP 5·3
- 자식의 공격력 20, 무보상, 무퀘스트, 재분열 방지, 최대 3마리
- 불꽃 도깨비의 순간이동 후보 검사, 안전 위치 선택, 실패 시 원위치 유지
- 고대 멧돼지의 잠복 중 비대상 상태, 방향 고정, 돌진과 장애물 종료
- 이끼 트롤의 위장 조건, 접근·피격 해제, 3초 후 재생, 초당 4, 최대 HP 제한
- 고대 버섯충의 예고 범위, 둔화 0.65와 2.5초, 비중첩 갱신, 4초 재사용시간
- 큰 `dt`에서도 공격·분열 이벤트가 중복되지 않음

### 통합 및 회귀 테스트

- 신규 스폰이 월드 경계, 장애물, 포털 안전범위와 겹치지 않음
- 신규 몬스터 처치 시 퀘스트와 무관하게 정확한 보상 지급 및 저장
- `magma-slime-small` 처치 시 보상·저장·슬라임 퀘스트 진행 없음
- 둔화가 실제 이동 거리에만 적용되고 공격과 포털 판정에는 영향 없음
- 사망, 부활, 지역 이동, 퇴장, 재입장에서 둔화와 행동 이벤트 초기화
- 기존 5종의 추적, 접촉 피해, 피격, 사망, 보상 범위 유지
- 기존 아렌 퀘스트, 미아 상점, 물약, 인벤토리, 채팅 입력 우선순위 유지
- 한 공격 다중 처치의 HUD 갱신과 저장 한 번 규칙 유지
- 모든 `src/*.js` 구문 검사와 diff 공백 검사 통과

### 브라우저 플레이 점검

- 세 지역에서 기존 몬스터와 신규 몬스터가 확정 수량으로 함께 보인다.
- 각 신규 몬스터의 외형과 지역별 색상이 서로 구분된다.
- 돌진선, 물기, 분열, 순간이동 잔상, 흙먼지, 위장·재생, 포자 범위가 실제 전투에서 식별된다.
- 고위력 공격은 준비 표시 후 한 번만 피해를 주며 무예고 연속 피해가 없다.
- 포자 둔화의 이동 차이와 해제 시점을 확인할 수 있다.
- 신규 몬스터 처치 직후 EXP·Gold가 HUD에 반영되고 재접속 후 유지된다.
- 지역 최대 16개체와 분열 자식 3개가 동시에 있어도 목표 50~60 FPS를 유지하고 지속적으로 45 FPS 아래로 내려가지 않는다.
- 게임 페이지에서 신규 JavaScript 오류가 발생하지 않는다.

모든 자동화 테스트와 브라우저 점검이 통과하면 구현을 완료한 것으로 본다.
