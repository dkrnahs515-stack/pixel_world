# 검사·궁수·마법사 직업 및 21종 무기 시스템 설계

## 목표

현재 닉네임만 입력하는 입장 화면에 검사·궁수·마법사 선택을 추가한다. 세 직업은 외형만 다른 선택지가 아니라 HP·MP·이동속도, 기본 공격, Q 스킬, 무기 성장 단계가 서로 다른 실제 플레이 방식으로 구현한다.

플레이어는 같은 닉네임으로 접속할 때마다 직업을 다시 선택할 수 있다. 레벨, EXP, Gold, 퀘스트, 물약은 세 직업이 공유하고, 보유 무기와 마지막 장착 무기는 직업별로 따로 보존한다.

## 범위

이번 작업에 포함한다.

- 입장 화면의 검사·궁수·마법사 선택
- 직업별 능력치, 기본 공격, Q 스킬
- 검사 7종, 궁수 7종, 마법사 7종의 총 21종 무기
- 현재 직업에 맞춘 대장간 구매·판매와 인벤토리 장착
- 직업별 장비 저장과 기존 v4 진행 데이터의 무손실 이전
- 직업과 장착 무기의 Firebase 동기화
- 세 직업 및 검·활·지팡이의 로컬·원격 캐릭터 외형
- 기존 게임 기능의 회귀 검증과 두 배포본 실플레이 검증
- README의 조작법, 직업, 무기 정보 갱신

이번 작업에서 제외한다.

- 게임 실행 중 즉시 직업 변경
- 전직 NPC 또는 전직 비용
- 플레이어 간 전투
- 원격 플레이어 공격의 피해 판정
- 상태이상, 소환수, 버프, 방어구
- 무기 강화 확률, 제작, 내구도, 수리
- 마우스 조준과 대각선 조준

## 확정된 사용자 흐름

1. 입장 화면에서 닉네임을 입력한다.
2. 검사·궁수·마법사 중 하나를 선택한다.
3. 선택한 직업에 따라 입장 버튼이 `검사로 입장`, `궁수로 입장`, `마법사로 입장`으로 바뀐다.
4. 닉네임과 직업이 모두 유효해야 입장할 수 있다.
5. 게임은 닉네임의 공통 진행 데이터와 선택 직업의 장비 데이터를 불러온다.
6. 같은 닉네임으로 재접속할 때 직업을 다시 고를 수 있다.
7. 직업을 바꾸면 그 직업에서 마지막으로 장착했던 무기가 복구된다.
8. 대장간과 인벤토리에는 현재 직업의 무기만 표시된다.
9. 다른 직업의 무기는 저장 상태로 유지되며 해당 직업으로 다시 접속하면 복구된다.

## 입장 화면

기존 판타지형 반투명 모달과 색상 체계를 유지하되 카드가 들어갈 수 있도록 최대 폭을 넓힌다.

- 상단: 게임 제목과 입장 안내
- 중단: 기존 닉네임 입력과 글자 수·오류 표시
- 하단: `직업 선택` 제목과 직업 카드 3개
- 직업 카드: 픽셀 캐릭터 미리보기, 직업 이름, 역할, Ctrl 공격, Q 스킬
- 선택 카드: 강조 테두리, 배경색, `선택됨` 상태
- 첫 접속: 아무 직업도 자동 선택하지 않고 사용자가 직접 선택
- 재접속: 브라우저에 마지막으로 기록된 유효 직업을 기본 선택하되 변경 가능
- 데스크톱: 3열
- 좁은 화면: 1열과 모달 내부 스크롤
- 입력: 포인터, Tab, 방향키, Space, Enter 지원
- 접근성: 직업 목록은 단일 선택 그룹으로 노출하고 선택 상태를 `aria-checked`로 제공
- 모션: 선택 전환에 짧은 색상·테두리 변화만 사용하고 `prefers-reduced-motion`을 존중

마지막 선택 직업은 진행 데이터와 분리된 브라우저 선호값으로 저장한다. 이 값은 편의를 위한 기본 선택일 뿐이며, 레벨·장비·퀘스트의 기준 데이터로 사용하지 않는다. 알 수 없는 값이면 선택하지 않은 상태로 시작한다.

## 직업 데이터

직업 정의는 DOM이나 게임 루프와 분리된 순수 데이터 모듈이 소유한다. 내부 ID는 다음 세 값만 허용한다.

- `warrior`: 검사
- `archer`: 궁수
- `mage`: 마법사

### 능력치

| 직업 | Lv.1 최대 HP | 레벨당 HP | Lv.1 최대 MP | 레벨당 MP | 이동속도(px/s) |
|---|---:|---:|---:|---:|---:|
| 검사 | 120 | 12 | 80 | 4 | 230 |
| 궁수 | 100 | 10 | 100 | 5 | 265 |
| 마법사 | 80 | 8 | 140 | 7 | 245 |

직업을 선택해 입장하거나 부활하면 해당 레벨과 직업의 최대 HP·MP로 회복한다. 레벨업 중에는 기존 동작처럼 최대치 증가를 반영하고 새 최대치까지 회복한다. 직업 변경은 로그인 사이에서만 일어나므로 전투 중 HP·MP 비율 이전은 필요하지 않다.

## 직업별 공격

모든 직업은 현재 네 방향 조작과 `Ctrl` 기본 공격, `Q` 스킬 입력을 유지한다. 기본 공격은 MP를 소비하지 않는다.

### 검사

- Ctrl: 현재 검의 전방 부채꼴 근접 공격
- 기본 공격 재사용시간: 0.5초
- Q: 플레이어 중심 360도 회전 베기
- Q 피해: 장착 검 피해의 2배
- Q 범위: 장착 검 기본 사거리 + 28px
- Q MP: 20
- Q 밀쳐내기: 520px/s
- Q 재사용시간: 장착 검의 스킬 재사용시간

기존 검 공격의 히트 스톱, 경직, 피해 숫자, 처치 보상 흐름을 보존한다.

### 궁수

- Ctrl: 바라보는 방향으로 한 발의 화살 발사
- 기본 공격 재사용시간: 0.55초
- 기본 화살: 첫 번째 적을 맞히면 피해를 주고 제거
- Q: 관통 화살
- Q 피해: 장착 활 피해의 2.2배
- Q 사거리: 장착 활 사거리의 1.35배
- Q 속도: 장착 활 투사체 속도의 1.1배
- Q 관통: 서로 다른 적 최대 5마리
- Q MP: 25
- Q 재사용시간: 장착 활의 스킬 재사용시간

같은 관통 화살은 적 하나에 한 번만 피해를 준다. 다섯 번째 적을 맞히거나 벽·월드 경계·최대 사거리에 도달하면 제거한다.

### 마법사

- Ctrl: 바라보는 방향으로 한 발의 마법탄 발사
- 기본 공격 재사용시간: 0.65초
- 기본 마법탄: 첫 번째 적을 맞히면 피해를 주고 제거
- Q: 폭발 마법탄
- Q 피해: 장착 지팡이 피해의 2.4배
- Q 사거리: 장착 지팡이 사거리의 1.25배
- Q MP: 30
- Q 폭발 범위: 장착 지팡이의 폭발 반경
- Q 재사용시간: 장착 지팡이의 스킬 재사용시간

폭발 마법탄은 첫 적, 장애물, 월드 경계 또는 최대 사거리에서 폭발한다. 폭발 반경 안의 표적 가능한 적 모두에게 한 번씩 피해를 준다.

## 투사체 규칙

화살과 마법탄은 게임 시뮬레이션의 고정 시간 단계에서 갱신한다.

- 플레이어 충돌 반경 밖의 무기 끝 지점에서 생성
- 생성 시 방향, 속도, 최대 사거리, 피해, 소유 직업, 공격 종류를 고정
- 렌더 프레임 사이에서 이전·현재 좌표를 보간
- 원형 또는 선분 기반 연속 충돌 검사로 빠른 투사체의 관통 누락 방지
- 표적 불가·사망 중인 몬스터는 무시
- 포탈 전환, 사망, 부활, 퇴장, 월드 변경 시 전부 제거
- 피해·경직·처치 보상은 기존 단일 처리 경로를 재사용
- 기본 화살과 마법탄은 첫 유효 적중만 처리
- 관통 화살과 폭발은 공격별 적중 ID 집합으로 중복 피해 방지

원격 플레이어의 투사체는 이번 범위에서 동기화하지 않는다. Firebase로 받은 직업과 장착 무기는 원격 외형에만 사용하며 로컬 몬스터 피해 계산에는 참여하지 않는다.

## 장비와 거래 상태

진행 데이터의 장비는 직업별로 분리한다.

```text
equipmentByClass
├─ warrior: ownedWeaponIds, equippedWeaponId
├─ archer: ownedWeaponIds, equippedWeaponId
└─ mage: ownedWeaponIds, equippedWeaponId
```

각 직업은 항상 자기 기본 무기를 보유한다. 직업과 다른 계열의 무기는 해당 직업의 보유 목록이나 장착 슬롯에 들어갈 수 없다.

### 대장간

- 대장간을 열면 현재 직업의 무기만 표시
- 현재의 구매·판매 탭 유지
- 구매 목록에는 기본 무기를 제외한 6개 무기 표시
- 판매 목록에는 현재 직업이 보유한 유료 무기만 표시
- 구매 조건: 알려진 무기, 현재 직업 일치, 요구 레벨, 충분한 Gold, 미보유
- 구매 성공: Gold 차감, 현재 직업 보유 목록에 한 번 추가, 자동 장착하지 않음
- 판매 조건: 알려진 무기, 현재 직업 일치, 기본 무기 아님, 실제 보유
- 판매 성공: Gold 증가, 보유 목록 제거
- 판매 무기가 장착 중이면 현재 직업 기본 무기로 교체
- 구매·판매 성공 후 HUD, 대장간, 인벤토리 갱신과 저장을 한 번 수행

### 인벤토리

- 물약은 기존처럼 세 직업 공용
- 장비 목록은 현재 직업의 7종만 표시
- 보유하지 않은 무기는 숨김
- 직업과 다른 무기 ID의 직접 장착 요청은 실패
- 장착 성공 시 현재 직업의 마지막 장착 무기를 변경하고 저장

대장간과 인벤토리는 21개 카드를 HTML에 중복 작성하지 않는다. 무기 데이터에서 현재 직업의 카드 목록을 생성해 기존 데이터 기반 갱신 흐름과 연결한다.

## 저장과 마이그레이션

로컬 진행 저장 버전을 v5로 올린다. v5는 기존 공통 진행 필드와 `equipmentByClass`를 가진다. 현재 선택 직업은 접속 세션 입력이며 공통 진행 데이터에 고정하지 않는다.

### v4에서 v5로 이전

- 레벨, EXP, 다음 레벨 EXP, Gold, 물약, 완료 퀘스트, 퀘스트 상태를 그대로 복사
- v4 `equipment`의 보유 검과 장착 검을 `equipmentByClass.warrior`로 이전
- 궁수는 `training-bow`만 보유·장착
- 마법사는 `training-staff`만 보유·장착
- 이전 결과를 v5 키에 저장
- 이전 저장 실패 시 메모리에서는 이전된 데이터로 계속 플레이하고 기존 v4 값을 삭제하거나 덮어쓰지 않음

v5의 공통 진행 필드가 유효하면 일부 직업 장비가 손상되어도 전체 진행을 버리지 않는다. 손상된 직업 장비만 해당 직업 기본 상태로 정규화한다. 공통 진행 필드 자체가 유효하지 않을 때만 새 진행 상태로 복구한다.

## 게임 구조

기능을 다음 경계로 분리한다.

- 직업 데이터: 이름, 설명, 능력치, 스킬, 색상, 기본 무기 ID
- 무기 데이터: 21종 정의와 직업별 조회·정규화
- 장비 상태: 직업별 보유·장착, 구매·판매·장착 순수 함수
- 투사체 전투: 생성, 고정 단계 이동, 연속 충돌, 관통·폭발 결과
- 렌더링: 직업 캐릭터, 검·활·지팡이, 화살·마법탄·폭발
- 진행 저장: v5 검증, 직업별 장비 정규화, v4 이전
- 게임 조정자: 입력, 현재 직업, 공격 실행, 적중 결과와 보상 연결
- 입장 UI: 닉네임과 직업 선택 검증, 마지막 직업 선호 저장, `enter(nickname, classId)` 호출

기존 대형 게임 모듈에 모든 분기를 직접 추가하지 않고 데이터와 투사체 판정을 독립 모듈로 둔다. 게임 모듈은 프레임 순서와 UI 연결만 담당한다.

## HUD와 렌더링

- 플레이어 패널에 현재 직업 이름 표시
- Q 슬롯 이름과 MP 비용을 직업별로 변경
- 쿨다운 표시는 기존 숫자 표시 재사용
- 입장 안내를 직업 조작에 맞게 변경
- 검사는 기존 검·칼집 외형 유지
- 궁수는 직업 색상, 활, 등에 멘 화살통을 표시
- 마법사는 직업 색상, 지팡이, 마법 핵심 장식을 표시
- 공격 중 검 휘두르기, 활 당기기, 지팡이 시전 자세를 구분
- 원격 플레이어도 동기화된 직업·무기로 동일한 대기·이동 외형 표시
- 알 수 없는 원격 직업은 검사, 맞지 않는 원격 무기는 해당 직업 기본 무기로 표시

캐릭터와 무기 미리보기는 기존 Canvas 도형 기반 픽셀 스타일을 사용한다. 새 이미지 파일이나 외부 에셋 의존성을 만들지 않는다.

## Firebase 동기화와 규칙

플레이어 위치 레코드에 다음 값을 추가한다.

- `classId`
- `equippedWeaponId`

클라이언트는 직업과 무기의 조합을 정규화한 뒤 게시한다. 수신 데이터도 신뢰하지 않고 같은 규칙으로 정규화한다.

Database Rules는 다음을 검증한다.

- `classId`는 `warrior`, `archer`, `mage` 중 하나
- `equippedWeaponId`는 알려진 21개 ID 중 하나
- 직업과 장착 무기 계열이 일치
- 기존 좌표, 방향, 이동 상태, 이름, 지역, 갱신 시각 검증 유지

배포 전환 중 기존 클라이언트가 끊기지 않도록 `classId`가 없는 레거시 플레이어 레코드는 검사로 간주하고 기존 검 ID만 허용한다. 새 클라이언트는 항상 `classId`를 게시한다.

## 예외 처리

- 입장 직업 미선택: 입장 차단 후 직업 선택 영역에 오류 표시
- 입장 화면에서 직업이 없거나 알 수 없는 값: 입장 차단 후 선택 없음으로 복구
- 실행 중 로컬 직업 상태가 알 수 없는 값으로 손상됨: 검사와 시작 검으로 안전 복구
- 알 수 없는 원격 직업: 검사 외형으로 복구
- 직업·무기 불일치: 해당 직업 기본 무기로 복구
- 기본 무기 판매: 거부
- 미보유 무기 판매·장착: 거부
- 레벨 또는 Gold 부족: 상태 변경 없이 거부
- 저장 실패: 플레이는 계속하되 진행 저장 실패 안내를 한 번 표시
- 투사체의 비정상 좌표·속도·수명: 즉시 제거
- 월드 전환·부활 중 입력: 기존 입력 차단 규칙 유지
- 폭발과 관통 중 적이 사망: 남은 처리를 계속하되 같은 공격의 중복 보상 방지

## 완료 조건

- 입장 화면에서 세 직업 중 하나를 선택해 게임에 들어갈 수 있다.
- 세 직업의 능력치, 기본 공격, Q 스킬이 설계대로 다르게 동작한다.
- 21종 무기의 구매·판매·장착·외형·전투 수치가 현재 직업에 맞게 작동한다.
- 재접속과 직업 변경 후 공통 진행과 직업별 장비가 정확히 복구된다.
- 기존 v4 이용자의 진행과 검 장비가 손실 없이 v5로 이전된다.
- 다른 플레이어의 직업과 장착 무기 외형이 정확히 보인다.
- Firebase Rules가 유효하지 않은 직업·무기 조합을 거부한다.
- 모든 자동 검사, 두 호스팅 배포, 세 직업 실플레이 검증이 성공한다.
