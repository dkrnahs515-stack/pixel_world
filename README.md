# 픽셀 월드 온라인 RPG

2D 픽셀 RPG 프로토타입입니다. 144Hz 모니터에서 `requestAnimationFrame()`을 통해 디스플레이 주사율에 맞춰 렌더링하며, 게임 로직은 144Hz 고정 타임스텝으로 처리합니다.

## 직업 선택과 저장

입장할 때 검사 · 궁수 · 마법사 중 하나를 선택합니다. 같은 닉네임으로 재접속해도 직업을 매번 변경할 수 있습니다. 레벨 · Gold · 퀘스트 · 물약은 모든 직업이 공유하며 그대로 유지되고, 직업별 무기 보유 목록과 마지막 장착 무기는 각각 독립적으로 보존됩니다.

| 직업 | 역할 | Ctrl 기본 공격 | Q 스킬 | Q MP |
|---|---|---|---|---:|
| 검사 | 근접 | 전방 검격 | 360도 회전 베기 | 20 |
| 궁수 | 원거리 | 화살 | 최대 5개 대상을 관통하는 관통 화살 | 25 |
| 마법사 | 범위 마법 | 마법탄 | 지팡이별 반경의 폭발 마법탄 | 30 |

직업마다 최대 HP·MP, 성장량과 이동 속도가 다릅니다. 투사체는 벽·지역 경계·최대 사거리에서 사라지며, 폭발 마법탄은 충돌 지점에서 범위 피해를 줍니다.

## 조작법

- `방향키`: 이동
- `Ctrl`: 선택 직업의 기본 공격
- `Q`: 선택 직업의 고유 스킬 — 직업별 MP 소모와 장착 무기별 재사용 대기시간 적용
- `F`: 가까운 NPC와 대화·상점 이용 또는 열린 NPC 화면 닫기
- `E / R`: 스킬 슬롯 — 현재 비어 있음
- `1`: 작은 체력 물약 사용 — HP 30 회복
- `2`: 작은 마력 물약 사용 — MP 25 회복
- `3`: 아이템 슬롯 — 현재 비어 있음
- `I`: 인벤토리 열기·닫기
- `Enter`: 전체 월드 채팅 입력 및 전송
- 채팅 입력 중 `Esc`: 채팅 취소
- 인벤토리·상점·대화 중 `Esc`: 현재 열린 화면 닫기
- 일반 상태의 `Esc`: 게임 나가기

## 첫 퀘스트: 모험의 시작

중앙 마을의 현자 아렌에게 가까이 간 뒤 `F`를 눌러 “모험의 시작” 퀘스트를 수락할 수 있습니다. 외부 지역의 화염 슬라임, 숲 슬라임, 물방울 슬라임 중 어떤 종류든 합계 3마리를 처치하고 아렌에게 돌아가 완료를 보고하면 EXP 15와 Gold 30을 획득합니다.

퀘스트 진행 상태와 누적 EXP는 현재 브라우저에 닉네임별로 저장됩니다. 같은 닉네임으로 다시 입장하면 진행 상황을 이어서 플레이하며, 다른 닉네임은 별도의 진행 데이터를 사용합니다.

## 브란 대장간과 21종 무기

- 검사 검 7종 · 궁수 활 7종 · 마법사 지팡이 7종, 총 21종의 단계별 무기가 있습니다.
- 중앙 마을의 대장장이 브란에게 `F`로 말을 걸면 대장간이 열리고 현재 직업 무기만 표시됩니다.
- 각 계열의 기본 무기는 처음부터 보유하며 판매할 수 없습니다. 상위 무기는 요구 레벨과 Gold를 충족하면 구매할 수 있습니다.
- 판매 가격은 구매 가격의 절반이며, 장착 무기를 판매하면 현재 직업의 기본 무기로 돌아갑니다.
- 인벤토리에는 현재 직업의 보유 무기만 나타나며 마지막 장착 상태는 직업별로 저장됩니다.

## 미아 상점과 인벤토리

- 중앙 마을의 연금술사 미아에게 가까이 가서 `F`를 누르면 물약 상점이 열립니다.
- 작은 체력 물약은 10 Gold, 작은 마력 물약은 15 Gold이며 종류별로 최대 99개까지 보유할 수 있습니다.
- `I` 키 또는 플레이어 패널의 가방 버튼으로 인벤토리를 열 수 있습니다.
- 인벤토리에는 현재 수량, 최대 수량, 회복 효과와 설명을 표시하며 `사용` 버튼을 클릭하거나 터치해 물약을 사용할 수 있습니다.
- 수량이 없거나 HP·MP가 이미 최대치이면 해당 사용 버튼이 비활성화됩니다.
- 인벤토리가 열려 있는 동안 이동, 공격, NPC 상호작용, 채팅 시작, 단축키 물약 사용을 차단합니다.
- 위험 지역에서 인벤토리를 연 채 피격되면 물약 사용 가능 상태를 갱신하며, 쓰러지면 부활 화면을 가리지 않도록 인벤토리를 자동으로 닫습니다.

## 전체 월드 채팅

- 왼쪽 아래 패널에는 모든 지역에서 보낸 최근 메시지를 최대 50개 표시합니다.
- 같은 지역에 있는 캐릭터 머리 위에는 해당 플레이어의 최신 메시지를 4초간 표시합니다.
- 말풍선은 한글·영문·복합 이모지를 여러 줄로 표시하며 최대 4줄 이후에는 말줄임표를 적용합니다.
- 말풍선 너비는 최대 240px 또는 화면 너비의 45%이며, 화면 가장자리 8px 안쪽으로 자동 보정됩니다.
- 위쪽 공간이 부족하면 캐릭터 아래로 이동하고 말꼬리 방향도 함께 반전됩니다.
- 플레이어별 최근 메시지는 최대 5개만 서버에 유지합니다.
- 정상 퇴장 또는 연결 종료 시 해당 UID의 모든 채팅 메시지를 삭제합니다.
- 채팅 입력 중에는 방향키 이동과 `Ctrl`·`Q` 공격 입력이 차단됩니다.

## 10배 확장 월드

기존 `2,880 × 1,800px` 맵을 네 지역, 합계 `51,840,000px²`로 확장했습니다. 전체 플레이 가능 면적은 기존의 정확히 10배입니다.

| 지역 | 크기 | 특징 |
|---|---:|---|
| 중앙 마을 | `2,880 × 1,800` | 마을 회관, 농장, 무역소, 상점·대장간, NPC, 몬스터 없는 안전지대 |
| 끓어오르는 활화산 | `4,320 × 3,600` | 현무암, 용암 강, 분화구, 화염 슬라임·마그마 슬라임·불꽃 도깨비 |
| 태고의 숲 | `4,320 × 3,600` | 거대한 고목, 숲길, 연못, 숲 슬라임·멧돼지·고대 멧돼지·이끼 트롤·고대 버섯충 |
| 푸른 해안가 | `4,320 × 3,600` | 모래사장, 부두, 난파선, 등대, 해안 게·물방울 슬라임·송곳니 상어·해적선 상어 |

중앙 마을의 빛나는 포탈에 들어가면 외부 지역으로 자동 이동합니다. 각 외부 지역의 귀환 포탈은 중앙 마을로 연결되며, 1초 재사용 잠금으로 즉시 되돌아가는 현상을 막습니다.

## 안전지대와 전투

- 중앙 마을의 몬스터 생성 목록은 비어 있어 몬스터가 나타나지 않습니다.
- 외부 몬스터는 자신의 지역 경계와 장애물을 벗어나거나 포탈을 이용할 수 없습니다.
- 기본 공격과 강한 공격으로 몬스터를 밀쳐내고 처치할 수 있습니다.
- 몬스터는 피격 시 점멸하고 흔들리며, 처치되면 서서히 사라집니다.
- 몬스터와 접촉하면 HP가 감소하고, HP가 0이 되면 중앙 마을에서 부활합니다.
- 송곳니 상어와 고대 멧돼지는 고정한 방향의 돌진선(고대 멧돼지는 흙먼지 포함)을 예고한 뒤 공격합니다. 해적선 상어의 물기는 입 점멸로 구분할 수 있습니다.
- 불꽃 도깨비는 사라지는 잔상 뒤 플레이어 근처에 재등장하며, 고대 버섯충은 보라색 포자 범위를 예고합니다. 이끼 트롤은 멀리 떨어지면 위장하고 피격 뒤 일정 시간이 지나면 체력을 회복합니다.
- 마그마 슬라임 부모는 처치 보상을 한 번 지급한 뒤 2~3마리의 작은 마그마 슬라임으로 분열합니다. 작은 자식은 다시 분열하지 않으며 EXP·Gold와 퀘스트 처치를 지급하지 않습니다.
- 고대 버섯충 포자에 맞으면 이동 속도가 2.5초 동안 0.65배가 됩니다. 포자는 중첩하지 않고 남은 시간만 갱신하며, 부활하거나 지역을 이동하면 즉시 해제됩니다.
- 몬스터 상태는 현재 각 플레이어의 브라우저에서 별도로 실행됩니다.

## 성능 구조

- 144Hz 고정 업데이트 + 렌더 보간
- 정적 월드 오프스크린 캐싱
- 화면 밖 엔티티 컬링
- 카메라 지수 보간
- 평균 FPS가 낮을 때 내부 렌더 해상도 자동 조절
- Firebase 위치·지역 전송은 초당 20회, 화면 표시는 프레임마다 보간
- Firebase는 원격 플레이어의 직업 · 장착 무기 외형을 동기화
- 같은 지역에 있는 원격 플레이어만 렌더링

몬스터 전투 시뮬레이션은 각 브라우저에서 독립적으로 실행됩니다. 원격 공격의 투사체와 피해는 동기화하지 않으므로 다른 플레이어의 공격이 내 화면의 몬스터 HP를 변경하지 않습니다.

144 FPS는 브라우저와 모니터가 144Hz 이상을 지원하고, 기기 성능이 충분할 때 표시됩니다. 게임이 모니터 주사율을 강제로 변경할 수는 없습니다.

## Firebase 온라인 연결

1. Firebase 프로젝트와 웹 앱을 생성합니다.
2. Authentication에서 익명 로그인을 활성화합니다.
3. Realtime Database를 생성합니다.
4. `src/config.js`의 `FIREBASE_CONFIG`에 Firebase 구성 객체를 입력합니다.
5. `database.rules.json` 내용을 Realtime Database 규칙에 적용합니다.

Firebase 설정이 없거나 연결에 실패하면 자동으로 오프라인 모드로 실행됩니다.
오프라인 모드에서는 채팅 입력창이 비활성화되며 이동·전투·포탈·나가기 기능은 계속 사용할 수 있습니다.

## 자동 품질 검사

`main` 대상 Pull Request와 `main` 변경에는 GitHub Actions의 `Verify game` 검사가 자동으로 실행됩니다.

- Node.js 24에서 게임 로직·저장·정적 UI 테스트 전체 실행
- 모든 `src/*.js` 파일의 JavaScript 문법 검사
- 자동 테스트 수는 변경마다 전체 실행 결과로 확인
- Playwright가 필요한 실제 브라우저 조작 테스트는 포함하지 않으며 Pages 실플레이에서 별도로 확인

검사에 실패한 Pull Request에는 빨간 실패 상태가 표시됩니다. 저장소에서 `Game tests and JavaScript syntax`를 필수 검사로 지정하면 실패한 변경의 `main` 병합을 차단할 수 있습니다.
