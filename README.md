# 픽셀 월드 온라인 RPG

> **조각난 데이터의 대륙, 당신의 손끝에서 세계의 형태를 되찾습니다.**

`Pixel World Online RPG`는 웹 브라우저에서 바로 플레이하는 2D 픽셀 RPG입니다. 검사·궁수·마법사 중 하나를 선택해 혼자 스토리를 진행하거나, 온라인 공개방에서 최대 10명의 플레이어와 채팅하고 협동 보스를 공략할 수 있습니다.

공식 플레이 주소: https://dkrnahs515-stack.github.io/pixel_world/

## 첫 플레이와 세계관

새 닉네임으로 처음 입장하면 중앙 초원에 나타나기 전 1회성 프롤로그가 재생됩니다. 시스템 오류와 잔류 코어 신호를 통해 플레이어가 알고 있는 초기 세계관을 보여 주되, 제4장에서 밝혀지는 사건의 진실은 미리 공개하지 않습니다.

대륙의 형태와 생명을 유지하던 `픽셀 코어`에 이상이 생긴 뒤 태고의 숲·푸른 해안·활화산에서 서로 다른 세 코어 반응이 발견되었습니다. 사람들은 이를 세 개의 코어 조각이라고 부르며, 플레이어는 아렌의 안내를 따라 세 지역을 조사하고 마지막에 픽셀 코어 성역에 도달합니다.

인트로 중에는 이동·공격·채팅·인벤토리 입력이 잠깁니다. `Enter` 또는 `Space`로 현재 타이핑을 완성하고 다음 장면으로 진행할 수 있으며, 건너뛰기 버튼도 제공합니다. `prefers-reduced-motion` 환경에서는 문자 단위 애니메이션과 도착 글리치를 줄입니다.

- 새 닉네임: `introSeen: false`로 시작해 최초 1회 인트로를 봅니다.
- 같은 닉네임 재접속/직업 변경/솔로↔온라인 전환: 다시 재생하지 않습니다.
- 기존 v1~v7 저장을 v8로 이전한 플레이어: 기존 이용자로 간주해 인트로를 강제하지 않습니다.
- 개발 중 생성된 v8 저장에 `introSeen`이 없다면 새 인트로를 한 번 보여 줍니다.
- 인트로 확인 저장에 실패해도 현재 게임 세션 자체는 막지 않습니다.

HUD의 `?` 도움말에서는 게임 소개, 3개 직업, 장비 성장, 솔로/온라인 차이와 조작법을 언제든 다시 확인할 수 있습니다.

## 플레이 모드

- **솔로 플레이**: Firebase 모듈을 불러오지 않고 서버 요청 없이 스토리 전체를 플레이합니다. 온라인 플레이어·채팅·접속자 수 UI를 숨깁니다.
- **온라인 플레이**: 최대 10명이 하나의 공개방을 사용합니다. 같은 물리 맵의 플레이어 위치/외형과 전체 채팅을 공유하고 지역 협동 보스 및 최종 보스 ORIGIN-0을 함께 상대합니다.
- 온라인 연결이 5초 이상 끊기면 레벨·Gold·퀘스트·장비·챕터 진행을 유지한 채 솔로 모드로 전환합니다. 공유 보스 HP는 솔로 보스에 이어 붙이지 않습니다.

## 직업과 성장

| 직업 | Lv.1 HP / MP | Ctrl | Q | E (Lv.5) | R (Lv.10) |
|---|---:|---|---|---|---|
| 검사 | 120 / 80 | 전방 검격 | 회전 베기 | 돌진 베기 | 연속 검격 |
| 궁수 | 100 / 100 | 화살 | 관통 화살 | 세 갈래 화살 | 화살비 |
| 마법사 | 80 / 140 | 마법탄 | 폭발 마법탄 | 빙결탄 | 운석 낙하 |

레벨이 오르면 직업별 최대 HP·MP와 공격 보너스가 증가합니다. MP는 생존 중 2초마다 최대 MP의 2%(최소 1)씩 회복됩니다.

## 조작법

- 이동: `↑` `←` `↓` `→`
- 기본 공격: `Ctrl`
- 직업 Q 스킬: `Q`
- 추가 스킬: `E`(Lv.5), `R`(Lv.10)
- 상호작용/조사/NPC 대화: `F`
- 체력 물약: `1`
- 마력 물약: `2`
- 특수 아이템 슬롯: `3` (현재 비어 있음)
- 인벤토리: `I`
- 온라인 전체 채팅: `Enter`
- 현재 화면 닫기/게임 나가기: `Esc`

## 첫 퀘스트와 챕터 진행

새 플레이어는 중앙 초원에서 현자 아렌과 대화해 `[모험의 시작]` 임무를 수락합니다. 외부 지역의 슬라임을 합계 3마리 처치하고 아렌에게 보고하면 EXP 15와 Gold 30을 받습니다.

HUD의 챕터 목표는 실제 진행도에 맞춰 바뀝니다.

1. **CHAPTER 1 · 태고의 숲** — 아렌의 첫 임무를 완료하고 숲의 코어 반응을 추적합니다.
2. **CHAPTER 2 · 푸른 해안** — 코어 연구원 세라의 조난 신호와 왜곡된 통신 기록을 추적합니다.
3. **CHAPTER 3 · 활화산** — 선발대를 추적하고 오염된 대장과 세 번째 코어 조각의 진실을 확인합니다.
4. **CHAPTER 4 · 픽셀 코어 성역** — 세 권한의 정체와 사건의 원인을 밝히고 세계의 최종 방향을 결정합니다.
5. 성역 완료 후 HUD는 `EPILOGUE · PIXEL WORLD 제1부 완료`로 전환됩니다.

이미 후반 지역까지 진행한 저장에 오래된 첫 퀘스트 상태가 남아 있어도 HUD를 CHAPTER 1로 되돌리지 않습니다. 월드 진행이 퀘스트 표시보다 우선합니다.

## 브란 대장간과 장비

검·활·지팡이 각 7단계, 총 21종의 일반 장비가 있습니다. 브란의 대장간에서는 현재 직업 장비만 구매·판매하고, 판매 가격은 구매 가격의 50%입니다. 시작 장비는 판매할 수 없으며 직업별 보유·장착 상태는 독립적으로 저장됩니다.

활화산에서 선발대장 구조에 성공하면 검사 `불굴의 화심검`, 궁수 `불굴의 잿불궁`, 마법사 `불굴의 용맥지팡이`를 함께 획득합니다. 이 세 장비는 보상 전용이며 구매·판매할 수 없고 자동 장착되지 않습니다.

## 미아 상점과 인벤토리

- 작은 체력 물약: 10 Gold / HP 30 회복
- 작은 마력 물약: 15 Gold / MP 25 회복
- 종류별 최대 9,999개
- `I` 또는 가방 버튼으로 인벤토리를 엽니다.
- 상점·인벤토리·대화 등 모달이 열린 동안 전투 입력을 차단합니다.

새 캐릭터는 Gold 0으로 시작하므로 첫 아렌 대사는 미아에게서 무료 물약을 지급받는다고 안내하지 않습니다. 물약 사용법과 브란의 장비 체계를 확인하도록 안내합니다.

## 제4장: 픽셀 코어 성역

성역에서 세 조각이 단순한 파편이 아니라 `생명·생성`, `기억·정보`, `에너지·제어` 관리자 권한이라는 사실이 드러납니다.

- 공명 회랑: 세 공명 장치를 모두 활성화해야 원점 기록고가 열립니다.
- 원점 기록고: 아렌의 권한 분리, 선발대 재진입, 대장의 긴급 코어 접속과 최종 방어 프로토콜을 순서대로 복원합니다.
- 제로 경계: 결함 픽셀·코어 감시자·재작성 잔상이 등장하며 개인 중간 보스 `TRINITY`를 상대합니다.
- 코어 심장부: 최종 방어 프로그램 `ORIGIN-0 — 최초의 수호자`와 싸우고 세계의 방향을 결정합니다.

### TRINITY

TRINITY는 솔로/온라인 여부와 관계없이 **개인 로컬 보스**입니다. 기본 HP는 800이며 생명 → 기억 → 에너지 → 혼합 형태로 전환됩니다. `BOSSKILLBOSS` 코드로 수가 늘어나지 않습니다.

### ORIGIN-0

ORIGIN-0의 솔로 기본 HP는 1,200입니다. 온라인에서는 `sanctuary-core-heart`의 하나의 공유 encounter를 사용하며 HP·Phase·앵커와 authority lease를 공유합니다. 현재 authority가 이탈하면 다른 참가자가 마지막 확정 상태를 이어받습니다.

ORIGIN 처치 기여자는 자신의 v8 저장에 개인 처치 영수증을 먼저 남깁니다. 해당 플레이어는 엔딩을 결정하기 전까지 ORIGIN spectator가 되어 나중에 재등장한 공유 ORIGIN을 공격하거나 피해받거나 렌더링하지 않습니다. 다른 플레이어의 전투는 계속됩니다.

## 세 엔딩

ORIGIN-0을 제압하면 다음 선택이 열립니다.

- **복원 — 원래의 세계** → 칭호 `세계의 복원자`
- **봉인 — 지켜낸 현재** → 칭호 `코어의 수호자`
- **공명 — 새로운 세계** → 칭호 `세계의 공명자`
- **결정 보류** → 엔딩을 확정하지 않고 성역 탐사로 복귀

공명은 선택 탐사물인 `원점 기록 3/3`이 필요합니다. 기록이 부족해도 `결정 보류` 후 되돌아가 수집할 수 있고 ORIGIN을 다시 싸울 필요가 없습니다. 첫 확정 엔딩은 닉네임별 영구 선택이며 다른 온라인 플레이어의 엔딩 선택과 서로 영향을 주지 않습니다.

엔딩 보상은 EXP 500 + Gold 1,000 + 비전투 칭호이며 한 번만 지급됩니다. 선택은 보상보다 먼저 저장하고, 보상 저장이 실패하면 재접속 후 안전하게 한 번만 재시도합니다.

크레딧은 30초이며 5초가 지나야 건너뛸 수 있습니다. 종료 또는 스킵 뒤 `UNKNOWN NODE SIGNAL DETECTED / SOURCE: OUTSIDE CORE RANGE` 포스트 크레딧을 거쳐 중앙 마을로 돌아옵니다.

## 저장

현재 저장 키는 닉네임별:

`pixel-world.progress.v8:<nickname>`

v8에는 레벨, EXP, Gold, 물약, 코드 보상, 직업별 장비, 협동 보스 보상 영수증, `introSeen`, 해안/활화산/성역 진행, ORIGIN 개인 처치 영수증, 엔딩 선택과 칭호가 포함됩니다.

v8을 먼저 읽고, 없거나 읽을 수 없으면 v7 → v1 순서로 가장 최근의 정상 저장을 찾아 v8로 이전합니다. 이전 버전 키는 자동 삭제하지 않습니다. 현재 위치는 저장하지 않으므로 일반 재접속은 중앙 마을에서 시작합니다.

## 온라인 데이터 경계

Firebase에는 온라인 플레이에 필요한 presence·채팅·공유 ORIGIN encounter·단기 defeat claim만 저장합니다. 다음은 Firebase에 올리지 않습니다.

- `introSeen`
- 개인 퀘스트/챕터 진행
- 엔딩 선택
- 엔딩 칭호
- TEACHER/BOSSKILLBOSS 솔로 권한

자세한 규칙은 `FIREBASE_SETUP.md`를 참고하세요.

## 보상 코드

현재 코드: `JAEHOON`, `MINAH`, `KANGIN`, `JOOHYEONG`, `NOISE`, `SLIME`, `BOSSKILLBOSS`, `TEACHER`.

`TEACHER`와 `BOSSKILLBOSS`의 특수 효과는 솔로 전용입니다. 온라인 presence에 전송하지 않으며 `BOSSKILLBOSS`는 기존 숲·해안·활화산 지역 보스에만 적용되고 TRINITY/ORIGIN에는 적용되지 않습니다.

## 개발·검증

정적/단위 테스트:

```bash
node --test tests/*.test.mjs tests/*.static.test.cjs
for file in src/*.js; do node --check "$file"; done
node --check tests/sanctuary-browser-smoke.cjs
```

브라우저 회귀 테스트는 기존 솔로·기본·채팅·해안·활화산 흐름 뒤에 `tests/sanctuary-browser-smoke.cjs`를 실행합니다. 성역 테스트는 첫 플레이 인트로, 공명 엔딩 완주, 결정 보류/기록 복구, 보상 재지급 방지를 검증합니다.

릴리스 브라우저 진입점은 `./src/main-20260910-sanctuary.js`, CSS는 `./styles-20260910-sanctuary.css`입니다. 변경된 전이 ES 모듈은 같은 물리 릴리스 그래프를 사용해 GitHub Pages/Firebase Hosting의 구버전 캐시 혼합을 방지합니다.
